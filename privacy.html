Privacy Policy

Last updated: 28 October 2026

This policy covers two private tools used by the owner of the YouTube channel Household Math: "Household Math uploader" and "Household Math Topic Research" (each an "App"). Neither has any users other than the owner.

Household Math Topic Research

Topic Research uses YouTube API Services with an API key, without any Google sign-in. It reads only public data: video titles, view counts and publish dates, channel statistics, and the text of public comments. It does not access any private data or any user's account.

The data is stored only on the owner's own computer and is used to build summary tables for choosing video topics. It is never published, shown to anyone else, sold, or shared. Raw data received from YouTube API Services is deleted or refreshed within 30 days of retrieval; only aggregate figures computed from it are kept.

To ask for the deletion of any of your data, contact the owner through the channel (see Contact below); it will be removed within 7 days.

YouTube API Services

Both Apps use YouTube API Services. By using an App you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Household Math uploader: what it accesses

With the channel owner's consent through Google sign-in (OAuth 2.0), the App accesses the owner's YouTube channel to upload the channel's own videos, set their titles, descriptions, thumbnails and publishing schedule, and read back the status and statistics of those videos. It does not access, collect or store data about any other user.

Storage and sharing

The uploader stores its Google access token only on the channel owner's own computer. It sends data only to Google through the YouTube API Services. No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time on the Google security settings page. Deleting the stored token on the owner's computer removes the App's copy.
